Week 12 — Context-Specific AI Guidelines

Risk profiles, professional rules, verification thresholds, and Final Project Gate 1

TipThis week’s central question

Why can the same AI action be acceptable in one context and irresponsible in another?

Learning goals

By the end of this week, you should be able to:

  1. distinguish a general risk-management framework from a profession-specific rule;
  2. identify how stakes, reversibility, confidentiality, and duty of care change acceptable AI use;
  3. define a verification threshold appropriate to a task;
  4. identify when sensitive or confidential information should not be entered into an AI system;
  5. construct context-specific AI-use guidelines;
  6. submit three discipline-specific Final Project task candidates with risk and verification plans.

Before class

REQUIRED READ A — NIST Generative AI Profile

Open the NIST profile

NIST’s profile is cross-sectoral.

Its value for this course is not a list of universal prohibitions.

It is the idea that risk controls should reflect:

goals + context + risk tolerance + affected people + available safeguards

TRACE Lab

Session 1 — General principle, specific rule

Today’s Case

Consider the same AI function:

Summarise a document.

Now place it in four contexts:

  • public news article;
  • confidential HR file;
  • medical note;
  • student’s own lecture notes.

Predict

Should the same rule apply in all four cases?

What changes?

Encounter — Risk dimensions

Use the following dimensions:

  • stakes
  • reversibility
  • confidentiality
  • affected people
  • source sensitivity
  • verification difficulty
  • time pressure
  • professional duty
  • consequence of error

Probe — Change one contextual variable

Take one AI use case and alter only:

  • confidentiality;
  • stakes;
  • affected population;
  • reversibility.

Does your acceptable-use rule change?

Why?

Session 2 — From framework to policy

Compare NIST and AP

Ask:

  • Which document is more general?
  • Which defines operational boundaries?
  • Which risks are specific to journalism?
  • Which principles transfer to other professions?

Pair Challenge — Write a mini-policy

Choose a professional context.

Write five rules:

  1. acceptable use;
  2. prohibited/high-risk use;
  3. verification requirement;
  4. disclosure requirement;
  5. human responsibility.

Decide

Does the policy control the actual risk, or merely the presence of AI?

Session 3 — Final Project Gate 1

The Final Project contains three authentic discipline-specific tasks.

Today you propose all three.

For each candidate task define:

Task → Why it matters → AI role → Risk → Verification → Evidence artifact

Gate 1 criteria

Each task must be:

  • authentic enough to matter outside the classroom;
  • feasible within the course;
  • different enough to reveal transfer;
  • low enough risk to conduct safely;
  • capable of independent verification;
  • capable of producing inspectable evidence.

Gate 1 outcome

Each proposed task receives:

  • APPROVE
  • REVISE
  • REPLACE

After class

Task 12 — Final Project Gate 1

Submit three candidate Final Project tasks.

For each task provide:

  1. task title;
  2. discipline/professional context;
  3. authentic purpose;
  4. expected AI role;
  5. main risks;
  6. confidentiality/data concerns;
  7. independent verification plan;
  8. evidence you will preserve;
  9. expected failure mode;
  10. why this task adds something different from the other two.

Finish with:

  1. proposed cross-task comparison question;
  2. initial idea for your Personal AI/LLM Use Charter;
  3. AI-use disclosure.
