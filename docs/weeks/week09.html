Week 9 — Context Drift

Context windows, relevance, lost-in-the-middle effects, state management, and strategic resets

TipThis week’s central question

If a model can accept more context, does that mean it can use all of that context equally well?

Learning goals

By the end of this week, you should be able to:

  1. distinguish context-window capacity from effective context use;
  2. explain the lost-in-the-middle finding at a conceptual level;
  3. identify irrelevant, stale, conflicting, and missing context;
  4. use a compact context brief to stabilise a long task;
  5. recognise when a fresh session or context reset is preferable to continued prompting;
  6. test context sensitivity through controlled variants.

Encounter — Capacity versus use

Separate:

Context capacity
How much information can enter the interaction?

from

Context utilisation
How reliably can the model use the information relevant to the task?

Probe — Position test

Run equivalent questions against the three context arrangements.

Record:

  • whether the answer changes;
  • whether the correct evidence is cited;
  • whether irrelevant material is used.
NoteImportant inference boundary

A classroom test can reveal sensitivity in the tested model and task.

It does not prove that every model always exhibits the same positional pattern.

Session 2 — Context drift in conversations

Four context problems

Irrelevant context
Information that is present but not useful.

Stale context
Earlier assumptions that are no longer valid.

Conflicting context
Instructions or facts that point in different directions.

Missing context
Information required for a defensible answer but never supplied.

Context Brief

Build a compact state record:

Goal → Known facts → Constraints → Decisions already made → Open questions → Evidence standard

Use the brief to start a fresh session.

Pair Challenge — Continue or reset?

Given a long messy conversation, choose:

  • continue;
  • summarise and continue;
  • create a context brief and reset;
  • start again from primary evidence.

Defend the choice.

Session 3 — Context stress test

Controlled conditions

Use the same target task under:

A — Compact relevant context
B — Long mixed context
C — Long context with a contradiction
D — Fresh session with a context brief

Compare:

  • instruction fidelity;
  • factual fidelity;
  • omission;
  • contradiction handling;
  • verification burden.

Decide

Which condition provides the best usefulness-to-verification-cost ratio?

Verify

Check whether the model used the source evidence you intended it to use.
